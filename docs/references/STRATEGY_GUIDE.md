## 전략 개요

이 시스템은 다양한 매매 전략을 제공하며, 각 전략은 독립적으로 선택하고 파라미터를 조정할 수 있습니다.
실시간으로 전략을 전환하여 시장 상황에 맞게 대응할 수 있습니다.

### 전략 구조
- **매수 전략**: 언제 주식을 살 것인가
- **매도 전략**: 언제 주식을 팔 것인가
- **파라미터**: 각 전략의 세부 설정

## 매수 전략

### 1. 모멘텀 전략 (Momentum Strategy)

**개념**: 급격한 상승세와 거래량 증가를 포착하여 매수

**장점**:
- 단기 급등주 포착에 유리
- 강한 상승 추세 활용
- 빠른 수익 실현 가능

**단점**:
- 고점 매수 위험
- 급등 후 급락 가능성
- 변동성이 큼

**추천 상황**:
- 시장이 강세일 때
- 단기 트레이딩 선호
- 적극적 투자 성향

**파라미터 설명**:

| 파라미터 | 설명 | 기본값 | 범위 | 추천 설정 |
|---------|------|--------|------|-----------|
| `min_change_rate` | 최소 등락률 (%) | 3.0 | 0.0 ~ 30.0 | 보수적: 5.0, 공격적: 2.0 |
| `min_volume_ratio` | 최소 거래량 비율 | 1.5 | 1.0 ~ 10.0 | 보수적: 2.0, 공격적: 1.2 |
| `max_position_size` | 최대 매수 금액 (원) | 1,000,000 | 100,000 ~ 10,000,000 | 리스크에 따라 조절 |

**사용 예시**:
```json
{
  "strategy_name": "momentum",
  "params": {
    "min_change_rate": 4.0,
    "min_volume_ratio": 1.8,
    "max_position_size": 1500000
  }
}
```

---

### 2. 가치 전략 (Value Strategy)

**개념**: 하락 후 반등 기회를 포착하여 저가 매수

**장점**:
- 안정적인 중장기 투자
- 낮은 가격에 매수
- 반등 시 큰 수익

**단점**:
- 추가 하락 가능성
- 보유 기간이 길 수 있음
- 인내심 필요

**추천 상황**:
- 시장 조정기
- 중장기 투자 선호
- 안정적 투자 성향

**파라미터 설명**:

| 파라미터 | 설명 | 기본값 | 범위 | 추천 설정 |
|---------|------|--------|------|-----------|
| `max_change_rate` | 최대 등락률 (음수, %) | -3.0 | -30.0 ~ 0.0 | 보수적: -2.0, 공격적: -5.0 |
| `min_price_ratio` | 최소 가격 비율 | 0.9 | 0.5 ~ 1.0 | 보수적: 0.85, 공격적: 0.95 |
| `max_position_size` | 최대 매수 금액 (원) | 1,000,000 | 100,000 ~ 10,000,000 | 리스크에 따라 조절 |

**사용 예시**:
```json
{
  "strategy_name": "value",
  "params": {
    "max_change_rate": -4.0,
    "min_price_ratio": 0.85,
    "max_position_size": 2000000
  }
}
```

### 3. 돌파 전략 (Breakout Strategy)

**개념**: 저항선(전일 고가) 돌파 시 추가 상승 기대하며 매수

**장점**:
- 강한 상승 모멘텀 포착
- 명확한 매수 신호
- 추세 추종에 유리

**단점**:
- 가짜 돌파 위험
- 단기 조정 가능성
- 변동성 큼

**추천 상황**:
- 박스권 돌파 시
- 강한 상승 추세
- 단기 트레이딩

**파라미터 설명**:

| 파라미터 | 설명 | 기본값 | 범위 | 추천 설정 |
|---------|------|--------|------|-----------|
| `breakout_threshold` | 돌파 기준 (%) | 2.0 | 0.5 ~ 10.0 | 보수적: 3.0, 공격적: 1.0 |
| `min_volume_increase` | 최소 거래량 증가율 (%) | 50.0 | 20.0 ~ 200.0 | 보수적: 100.0, 공격적: 30.0 |
| `max_position_size` | 최대 매수 금액 (원) | 1,000,000 | 100,000 ~ 10,000,000 | 리스크에 따라 조절 |

**사용 예시**:
```json
{
  "strategy_name": "breakout",
  "params": {
    "breakout_threshold": 2.5,
    "min_volume_increase": 80.0,
    "max_position_size": 1200000
  }
}
```

## 매도 전략

### 1. 고정 비율 전략 (Fixed Ratio Strategy)

**개념**: 설정한 수익률/손실률에 도달 시 자동 매도

**장점**:
- 명확한 손익 기준
- 감정 배제 가능
- 리스크 관리 용이

**단점**:
- 추가 상승 기회 놓칠 수 있음
- 시장 상황 미반영
- 유연성 부족

**추천 상황**:
- 명확한 목표가 설정
- 안정적 수익 추구
- 초보 투자자

**파라미터 설명**:

| 파라미터 | 설명 | 기본값 | 범위 | 추천 설정 |
|---------|------|--------|------|-----------|
| `take_profit_rate` | 익절 비율 (%) | 10.0 | 3.0 ~ 50.0 | 보수적: 7.0, 공격적: 15.0 |
| `stop_loss_rate` | 손절 비율 (음수, %) | -5.0 | -30.0 ~ -1.0 | 보수적: -3.0, 공격적: -7.0 |
| `partial_sell_ratio` | 부분 매도 비율 | 0.5 | 0.0 ~ 1.0 | 전체 매도: 1.0, 절반: 0.5 |

**사용 예시**:
```json
{
  "strategy_name": "fixed_ratio",
  "params": {
    "take_profit_rate": 12.0,
    "stop_loss_rate": -4.0,
    "partial_sell_ratio": 0.6
  }
}
```

**부분 매도 설명**:
- `0.0`: 매도 안 함 (비추천)
- `0.5`: 보유 주식의 절반만 매도 (추천)
- `1.0`: 전체 매도

---

### 2. 후행 손절 전략 (Trailing Stop Strategy)

**개념**: 고점 대비 일정 비율 하락 시 매도 (추세 추종)

**장점**:
- 상승 추세 최대한 활용
- 수익 극대화 가능
- 자동 손절 기능

**단점**:
- 급락 시 손실 확대 가능
- 일시적 조정에도 매도
- 복잡한 설정

**추천 상황**:
- 강한 상승 추세
- 수익 극대화 목표
- 경험 있는 투자자

**파라미터 설명**:

| 파라미터 | 설명 | 기본값 | 범위 | 추천 설정 |
|---------|------|--------|------|-----------|
| `trailing_stop_rate` | 후행 손절 비율 (%) | 5.0 | 2.0 ~ 20.0 | 보수적: 3.0, 공격적: 7.0 |
| `min_profit_activate` | 최소 수익률 활성화 (%) | 5.0 | 0.0 ~ 30.0 | 즉시 활성화: 0.0, 안전: 10.0 |
| `emergency_stop_loss` | 긴급 손절 (음수, %) | -10.0 | -30.0 ~ -5.0 | 보수적: -7.0, 공격적: -15.0 |

**사용 예시**:
```json
{
  "strategy_name": "trailing_stop",
  "params": {
    "trailing_stop_rate": 6.0,
    "min_profit_activate": 8.0,
    "emergency_stop_loss": -8.0
  }
}
```

**작동 원리**:
1. 주식 매수 후 `min_profit_activate` 수익률 도달 시 후행 손절 활성화
2. 이후 고점에서 `trailing_stop_rate`만큼 하락하면 매도
3. 그 전에 `emergency_stop_loss` 도달 시 즉시 매도

---

### 3. 변동성 기반 전략 (Volatility Based Strategy)

**개념**: 급격한 가격 변동 감지하여 리스크 관리

**장점**:
- 리스크 관리 중심
- 급락 조기 감지
- 손실 최소화

**단점**:
- 일시적 변동에도 반응
- 수익 기회 놓칠 수 있음
- 거래 빈도 높음

**추천 상황**:
- 변동성 큰 시장
- 리스크 회피 성향
- 단기 트레이딩

**파라미터 설명**:

| 파라미터 | 설명 | 기본값 | 범위 | 추천 설정 |
|---------|------|--------|------|-----------|
| `max_decline_rate` | 최대 하락률 (음수, %) | -5.0 | -20.0 ~ -2.0 | 보수적: -3.0, 공격적: -7.0 |
| `volume_spike_threshold` | 거래량 급증 기준 (배) | 3.0 | 2.0 ~ 10.0 | 보수적: 2.5, 공격적: 4.0 |
| `take_profit_rate` | 익절 비율 (%) | 15.0 | 5.0 ~ 50.0 | 보수적: 10.0, 공격적: 20.0 |

**사용 예시**:
```json
{
  "strategy_name": "volatility",
  "params": {
    "max_decline_rate": -4.0,
    "volume_spike_threshold": 2.5,
    "take_profit_rate": 12.0
  }
}
```

## 전략 사용법

### 1. 웹 UI를 통한 설정

1. 브라우저에서 `http://localhost:5000/strategy-config.html` 접속
2. 매수 전략 선택
   - 드롭다운에서 원하는 전략 선택
   - 파라미터 슬라이더로 조정
   - "매수 전략 저장" 클릭
3. 매도 전략 선택
   - 드롭다운에서 원하는 전략 선택
   - 파라미터 슬라이더로 조정
   - "매도 전략 저장" 클릭
4. 자동 매매 활성화 토글
5. 종목 코드 입력하여 전략 테스트

### 2. API를 통한 설정

#### 매수 전략 설정
```bash
curl -X POST http://localhost:5000/api/strategy/buy/set \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "strategy_name": "momentum",
    "params": {
      "min_change_rate": 3.0,
      "min_volume_ratio": 1.5,
      "max_position_size": 1000000
    }
  }'
```

#### 매도 전략 설정
```bash
curl -X POST http://localhost:5000/api/strategy/sell/set \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "strategy_name": "fixed_ratio",
    "params": {
      "take_profit_rate": 10.0,
      "stop_loss_rate": -5.0,
      "partial_sell_ratio": 0.5
    }
  }'
```

#### 현재 설정 조회
```bash
curl http://localhost:5000/api/strategy/current \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 시장 상황별 추천 전략

#### 📈 강세장 (Bull Market)

**매수**: 모멘텀 또는 돌파 전략
**매도**: 후행 손절 (수익 극대화)

**이유**: 상승 추세를 최대한 활용

---

#### 📉 약세장 (Bear Market)

**매수**: 가치 전략 (저가 매수)
**매도**: 고정 비율 (빠른 손절)

**이유**: 리스크 관리 중심

---

#### 📊 횡보장 (Sideways Market)

**매수**: 가치 전략
**매도**: 변동성 기반

**이유**: 변동성 활용한 단기 매매

---

### 전략 조합 예시

#### 조합 1: 안정적 장기 투자

```
매수: 가치 전략 (저가 매수)
```


#### 조합 3: 변동성 트레이딩
```
매수: 돌파 전략 (변동성 포착)
매도: 변동성 기반 (급변 대응)
```

## 주의사항

1. **과최적화 주의**: 파라미터를 너무 자주 변경하지 마세요
2. **백테스팅**: 실제 투자 전 충분히 테스트하세요
3. **리스크 관리**: 항상 손절 설정을 유지하세요
4. **분산 투자**: 한 종목에 모든 자금을 투자하지 마세요
5. **시장 모니터링**: 자동 매매라도 주기적으로 확인하세요

## 문제 해결

### Q1: 전략이 작동하지 않아요
- 자동 매매가 활성화되어 있는지 확인
- 파라미터가 너무 제한적이지 않은지 확인
- 로그 확인: `backend/app.py` 실행 로그

### Q2: 너무 자주 매매해요
- 파라미터를 더 보수적으로 설정
- `min_change_rate`, `min_volume_ratio` 증가
- 매수 금액 제한

### Q3: 매매를 안 해요
- 파라미터를 덜 제한적으로 설정
- 시장 상황 확인
- 전략 테스트 기능으로 분석 결과 확인
