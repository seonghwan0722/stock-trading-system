# Financial Data API Research & Documentation

## Project Overview
Research financial data APIs as alternatives to web scraping for stock market and congressional trading data.

## Target Data Categories
1. US Politicians' stock trading data
2. Real-time stock market data
3. Stock fundamentals and technical indicators
4. Exchange data and charts
5. Insider trading information
