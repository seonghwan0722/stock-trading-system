## 📋 요약

이 문서는 다음 데이터를 위한 금융 API를 종합적으로 비교합니다:
- 미국 정치인 주식 거래 데이터
- 실시간 주식 시세 및 시장 데이터

3. **내부자 거래**: SEC EDGAR가 구조화된 데이터 제공; 유료 API도 존재

## 1. 미국 의회 & 정치인 거래 데이터

### 1.1 Capitol Trades (capitoltrades.com)

**공식 API 상태**: ❌ 공개 API 없음
- 웹사이트가 JavaScript 렌더링 콘텐츠 사용
- 데이터는 SEC 신고서에서 수집된 것으로 보임

**공식 데이터 소스**:
- 미국 하원 SOAR 시스템
- 상원 eFILE 시스템
- 개인 재정 공개 양식

**권장 방법**: 웹 스크래핑 + SEC EDGAR API 조합

---

### 1.2 SEC EDGAR API

**가용성 & 접근**: ✅ 무료, 공개
- 웹사이트: https://www.sec.gov/edgar/browse/
- API 키 불필요
- 속도 제한: 초당 10회 권장

**데이터 범위**:
- Form 4 신고서 (내부자 거래)
- 주식 소유권 변경
- 의회 의원 공개 정보
- 기업 내부자 거래

**장점**:
- 완전 무료
- 공식 정부 데이터
- 포괄적인 내부자 거래 데이터
- 인증 불필요
- 실시간 업데이트

**단점**:
- HTML 기반 응답 (파싱 필요)
- 제한된 JSON 엔드포인트
- 느린 응답 시간
- 속도 제한 구현 필요
- 복잡한 데이터 구조

**사용 사례**: Form 4 내부자 거래 및 의회 거래 데이터의 기본 소스

## 2. 실시간 주식 시장 데이터

### 2.1 Polygon.io

**가용성 & 접근**: ✅ 무료 티어 + 유료
- 웹사이트: https://polygon.io
- API 키 필요
- 제한된 무료 티어

**무료 티어**:
- 주식, 암호화폐, 외환 데이터
- 분당 5회 API 호출
- 데이터 15-20분 지연
- 제한된 과거 데이터

**유료 티어**:
- Starter: $29/월 - 분당 100회
- Professional: $199/월 - 분당 1000회
- Enterprise: 맞춤형 가격

**데이터 범위**:
- 실시간 주식 시세
- 과거 OHLC 데이터
- 집계 (1분, 5분, 15분 등)
- 뉴스 및 감정
- 시장 휴일
- 기술적 지표

**장점**:
- 무료 티어 사용 가능
- 합리적인 지연으로 실시간 데이터
- 포괄적인 시장 커버리지
- 다양한 시간 프레임
- 좋은 문서
- 여러 자산 클래스 지원

**단점**:
- 무료 티어는 상당한 제한 (15-20분 지연)
- 무료 티어 엄격한 속도 제한
- 유료 플랜 비쌀 수 있음
- 실시간 데이터는 프리미엄 티어

**프로덕션 비용**:
- Starter ($29/월): ~20k API 호출/월
- Professional ($199/월): ~1.44M API 호출/월
- 주식 앱 예상: $200-500/월

**사용 사례**: 실시간 주가 및 과거 OHLC 데이터의 기본 소스

- Premium: $300/월 - 분당 300+회

**데이터 범위**:
- 실시간 주식 시세
- 과거 일별/분별 데이터
- 기업 재무제표
- 실적 데이터
- 경제 캘린더
- 암호화폐 데이터

**장점**:
- 무료 티어가 견고함 (60회/분)

## 4. 통합 전략 및 아키텍처

### 권장 하이브리드 접근법:

```
┌─────────────────────────────────────────┐
│    클라이언트 애플리케이션 (Web/Mobile)      │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│      백엔드 API (Node.js/Python)          │
└─────────────────────────────────────────┘
    ↓               ↓               ↓
┌─────────┐  ┌─────────┐  ┌─────────┐
│ 캐싱     │  │ 데이터베이스│  │ 큐      │
│ (Redis) │  │(PostgreSQL)│  │(Bull/RQ)│
└─────────┘  └─────────┘  └─────────┘
    ↓               ↓               ↓
┌─────────────────────────────────────────┐
│         데이터 집계 레이어               │
├─────────────────────────────────────────┤
│ • API 오케스트레이션                     │
│ • 속도 제한 관리                         │
│ • 데이터 정규화                          │
│ • 에러 처리 및 재시도                    │
└─────────────────────────────────────────┘
    ↓               ↓               ↓
┌─────────┐  ┌─────────┐  ┌─────────┐
│IEX Cloud│  │ Finnhub │  │SEC EDGAR│
│ (실시간) │  │(재무제표)│  │(내부자) │
└─────────┘  └─────────┘  └─────────┘
```

### 구현 전략:

#### Layer 1: 실시간 시세 (IEX Cloud)
- 5-15분마다 업데이트
- 비용: ~$70-100/월
- 캐시: 5분 TTL

#### Layer 2: 재무제표 (Finnhub)
- 매일 또는 매주 업데이트
- 비용: 무료 티어로 충분 (60회/분)
- 캐시: 7일 TTL

#### Layer 3: 기술적 지표 (Alpha Vantage 또는 Finnhub)
- 온디맨드 또는 매일 업데이트
- 비용: 무료 또는 $100/월 Alpha Vantage
- 캐시: 1일 TTL

#### Layer 4: 내부자 거래 (SEC EDGAR + 스크래핑)
- 매일 업데이트
- 비용: 무료 (스크래핑) + 인프라
- 캐시: 1일 TTL

#### Layer 5: 기업 뉴스 (Finnhub 또는 Polygon)
- 매시간 업데이트
- 비용: Finnhub 무료 티어 포함
- 캐시: 1시간 TTL

## 8. 웹 스크래핑 대신 API를 사용하는 이유

### 웹 스크래핑을 사용하지 않는 이유:

1. **취약성**: 웹사이트 변경 시 스크래퍼 중단
2. **법적**: 이용 약관 위반
3. **성능**: API보다 느림
4. **신뢰성**: SLA 또는 지원 없음
5. **비용**: 인프라 및 유지보수
6. **차단**: IP 차단, CAPTCHA, 속도 제한

### API를 사용하는 이유:

1. **신뢰성**: 가동 시간 SLA 보장
2. **속도**: 최적화된 인프라
3. **법적**: 승인된 데이터 접근
4. **지원**: 전문 지원 옵션
5. **일관성**: 표준화된 데이터 형식
6. **확장성**: 고용량을 위해 구축됨
